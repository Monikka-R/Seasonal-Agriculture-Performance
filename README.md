# Seasonal Agriculture Performance Analysis

## Project Overview

This project analyzes seasonal agricultural performance using Python and
data analytics techniques.

The analysis covers:

- Crop yield
- Seasonal performance
- Revenue and cost
- Profitability
- Irrigation methods
- Water-use efficiency
- Environmental conditions
- Disease and pest risk
- Correlation analysis

## Dataset

The dataset contains 4,000 agricultural records with 28 variables covering
crop, environmental, irrigation, production, and economic information.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
- GitHub

## How to Run

### Option 1 — Google Colab

Click the button below to open the notebook directly in Google Colab.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/Monikka-R/Seasonal-Agriculture-Performance/blob/main/Seasonal_Agriculture_Performance_Data_Analytics.ipynb)

After opening the notebook:

1. Go to **Runtime**
2. Select **Run all**
3. The dataset will be loaded automatically from GitHub.
4. All analysis results and visualizations will be generated.
